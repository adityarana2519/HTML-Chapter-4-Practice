# Chapter 4 – HTML Practice Set

This repository contains four beginner-friendly HTML exercises:

1. `video.html` — embeds a local MP4 video using the HTML `<video>` element.
2. `youtube-video.html` — embeds a YouTube video using an `<iframe>`.
3. `travel-booking.html` — travel/vacation booking form with input fields.
4. `cricket-score.html` — cricket scorecard using an HTML table.

`index.html` is the homepage that links to all four tasks.

## Run locally

Open `index.html` in a browser. Keep `myvideo.mp4` in the same folder as `video.html`.

## Publish with GitHub Pages

1. Create a public repository on GitHub.
2. Upload all files from this folder, including `myvideo.mp4`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes and open the Pages URL shown in Settings → Pages.

Note: The travel form is a front-end demo only; it does not create a real reservation.
